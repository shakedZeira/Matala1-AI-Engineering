# מטלה 1: עוזר עסקי ל-ShopIL (הנדסת מוצר AI)

עוזר עסקי לחנות ShopIL: נתוני עבר (dlt → DuckDB → dbt), זרם הזמנות וביקורות חי (מנוע הקורס עם SQLite),
וצ'אט Gradio עם **יוצר ומעריך** מעל חבילת ראיות קבועה לכל שאלה.

| תיקייה / קובץ | תוכן |
|---|---|
| [`shopil-assistant/`](shopil-assistant/README.md) | הקוד שפותח בעבודה (שכבת שליפה, יוצר ומעריך, צ'אט), הנחיות המודלים, ניסויים, יומנים וראיות. **התחילו מה-README שבתוכה.** |
| [`etl-course-demo-completed-files/`](etl-course-demo-completed-files/README.txt) | 5 הקבצים שהושלמו/נוספו על גבי מאגר ה-ETL של הקורס (הנחיות שילוב בתוכה) |
| [`דוח_מטלה_1.docx`](דוח_מטלה_1.docx) | הדוח הקצר, כולל תרשים, טבלת ניסויים וצילומי מסך |
| [`תרשים_ארכיטקטורה.png`](תרשים_ארכיטקטורה.png) | תרשים המימוש |

מאגרי הקורס עצמם (`etl-course-demo`, `streaming-course-demo`) אינם כלולים כאן ואינם שונו; ראו ב-README את הגרסאות המדויקות שבהן נעשה שימוש.
אין בריפו מפתחות גישה: יש להעתיק את `shopil-assistant/.env.example` ל-`.env` ולמלא מפתח משלכם.
